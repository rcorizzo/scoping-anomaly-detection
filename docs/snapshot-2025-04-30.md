## 4. Categories and Interpretation

The configuration contains 14 property groups: Main topics; Anomaly detection models; Supervision type; Computing type; Learning setting; Application Domain; Data modality; Data type; Data type detailed; Data source; AI models - DL; AI models - Shallow; Concerns; and Paper type.

Main topics and Application Domain carry `is_mandatory: true`, while the separate `properties_mandatory` list is empty. The original implementation is needed to establish how these settings interact. Likewise, the string-valued `relevant` option is retained without assigning an undocumented threshold interpretation.

The configurations contain broad and overlapping synonyms. For example, the supervision dictionary places `classification` and `regression` under supervised, `zero-shot` under unsupervised, and both one-class and limited-label phrases under semi-supervised. The learning-setting dictionary groups transfer learning with meta-learning and federated learning with privacy-preserving learning. These are archived coding choices, not independently validated task definitions.

Publicly depositing the dictionaries makes these choices inspectable; it does not establish classification precision, recall, agreement, or coverage.

## 5. Contact-Email Transformations

The public release excludes the original `emails.txt` file. Workbook `emails` data cells are blanked, and residual email-address strings in workbook XML and the BibTeX export are replaced with `[email redacted]`. XLSX contents are transformed directly as OOXML ZIP members so that unrelated workbook members remain unchanged. Contact strings in shared-string storage are also removed or redacted, rather than merely hiding their cells.

All other published files are copied from the archive. Each file's original and published hashes and transformation status appear in `data/2025-04-30/manifest.json`. This makes the public release distinguishable from the unchanged local originals and the original ZIP checksum.

## 6. Relationship to the Reviewed Manuscript

This snapshot has a configured start year of 2015 and a retained counter of 5,733. These differ from the reviewed manuscript's stated 2016-2025 interval and 19,884 retained studies. It must not be identified as the source of those later manuscript counts without a provenance reconciliation.

The presence of this archive does not establish exact executed Boolean queries, manual full-text screening, a preregistered protocol, classification validation, risk-of-bias appraisal, or the code version used. Later verified outputs should be deposited in a new snapshot directory, with the query logs, provenance, and corresponding manuscript figures identified.
